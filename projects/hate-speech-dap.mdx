## Overview

Developed as part of the **11th DAP (Data Associates Program) under SMUBIA (Business Intelligence & Analytics Club)**, this project addresses hate speech classification through two complementary tracks:

1. **Embedding Space Analysis & Traditional ML:** Using BERT and RoBERTa as embedding models to generate 768-dimensional text representations, then feeding those into traditional ML classifiers (Logistic Regression, XGBoost, Random Forest, MLP) to classify hate speech — investigating whether embeddings + traditional ML can match end-to-end deep learning.
2. **Agentic & Multi-Task Learning:** Exploring sarcasm-aware hate speech detection through multi-task learning, LLM agentic workflows, and Knowledge Graph RAG.

**Dataset:** HateXplain — 15,383 train / 1,924 test samples, with 3-class labels (Hate, Offensive, Normal) and annotator rationales.

## Track 1: Embedding Space Analysis

The central question: **can fine-tuned transformer embeddings + traditional ML classifiers match or rival end-to-end deep learning?**

### Embedding Geometry

We first measured the geometric structure of embeddings from vanilla (pre-trained) vs. fine-tuned encoders:

| Model | Silhouette | kNN Purity |
|---|---|---|
| Vanilla RoBERTa [cls] | −0.003 | 44.8% |
| Vanilla BERT [cls] | −0.004 | 41.0% |
| Fine-Tuned BERT Binary [cls] | +0.181 | 82.7% |
| Fine-Tuned RoBERTa 3-Class [cls] | +0.177 | 72.1% |

**Key finding:** Fine-tuning yields a ~50× improvement in cluster quality (silhouette ≈ 0.00 → ≈ 0.18). Vanilla models show near-zero or negative silhouette scores — classes are geometrically indistinguishable. Fine-tuning reshapes all 768 dimensions to create real cluster structure, making shallow classifiers effective.

### 3-Class Classification Results

| Embeddings | Classifier | Accuracy | Macro F1 |
|---|---|---|---|
| Fine-Tuned RoBERTa [cls] | XGBoost | **70.3%** | **0.691** |
| Fine-Tuned RoBERTa [cls] | Random Forest | 70.0% | 0.686 |
| Fine-Tuned RoBERTa [cls] | Logistic Regression | 68.8% | 0.681 |
| Fine-Tuned BERT [cls] | XGBoost | 69.5% | 0.684 |
| Vanilla RoBERTa [cls] | Logistic Regression | 62.2% | 0.610 |
| _End-to-end RoBERTa + classification head_ | _(reference)_ | _69.3%_ | _0.689_ |

The embedding + XGBoost approach **actually exceeds** the end-to-end RoBERTa baseline (70.3% vs 69.3%).

### Binary Classification Results

| Embeddings | Classifier | Accuracy | Macro F1 |
|---|---|---|---|
| Fine-Tuned BERT [rationale] | XGBoost | **86.5%** | **0.840** |
| Fine-Tuned BERT [rationale] | MLP (256→128→64) | 85.7% | 0.835 |
| _End-to-end BERT + classification head_ | _(reference)_ | _87.7%_ | _0.874_ |

Within **1.2%** of end-to-end fine-tuning — at a fraction of the compute cost.

### Key Insights

1. **Embeddings are the bottleneck, not classifiers.** Switching from vanilla to fine-tuned embeddings gains ~8% F1. Switching classifiers within the same embeddings changes only ~2–4% F1.
2. **The encoder's linear classification head is the weak link.** End-to-end fine-tuning of a domain-specific RoBERTa model achieved 70.0% accuracy — almost identical to frozen embeddings + XGBoost (70.3%). The encoder learns excellent representations, but its single `nn.Linear(768, 3)` head can't exploit them as well as XGBoost can.
3. **Traditional ML can match end-to-end deep learning.** The frozen encoder + XGBoost approach is faster to iterate, more modular, and requires no GPU for classifier training.

## Track 2: Sarcasm-Aware Hate Speech Detection

### Multi-Task Learning (BERT)

A shared encoder architecture with two distinct output heads:

- **Hate Head:** Predicts 3 classes (Hate, Offensive, Normal)
- **Sarcasm Head:** Predicts 2 classes (Sarcastic, Not Sarcastic)

By training these heads jointly on HateXplain (hate) and iSarcasmEval (sarcasm), the shared encoder learns representations sensitive to both semantic toxicity and ironic tone.

### LLM & Agentic Workflows

Implemented agentic classification using local LLMs (LLaMA-3-8B, Mistral via Ollama) with chain-of-thought prompting. The model reasons step-by-step: _Is this sarcastic? → If yes, does the sarcasm convey hate? → Final verdict._

### Knowledge Graph RAG (KG-RAG)

Explored KG-RAG to enrich classification with entity-level knowledge of slurs, dog whistles, and cultural references via Neo4j, reducing hallucination and improving detection of implicit hate.

## Datasets

- **HateXplain:** Core dataset for hate detection — labels for Hate, Offensive, Normal, plus annotator rationales for rationale-weighted pooling
- **iSarcasmEval:** Training data for the sarcasm detection head
- **Implicit Hate:** Testing the "Hateful + Sarcastic" intersection
- **TweetEval-Irony & ToxiGen:** Supplementary datasets for robustness testing
